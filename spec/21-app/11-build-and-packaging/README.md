```toml
[project]
name = "idle-shutdown"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
  "click>=8.1",
  "rich>=13.7",

  "pywin32>=306; sys_platform == 'win32'",
  "pyvda>=0.4; sys_platform == 'win32'",

[project.scripts]
idle-shutdown = "idle_shutdown.cli:main"

[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"
```
No additional runtime dependencies may be added without bumping the spec.

## PyInstaller spec (authoritative invocation)
```
pyinstaller build/idle-shutdown.spec --noconfirm --clean
```
`idle-shutdown.spec` MUST set:
- `name='idle-shutdown'`
- `console=False` (so `--silent` truly hides the window; the CLI re-attaches a console via `AllocConsole` when run interactively without `--silent`)
- `onefile=True`
- `icon='build/app.ico'`
- `version='build/version.txt'`
- `hiddenimports=['pyvda', 'win32timezone']`
- `datas=[('idle_shutdown/db/schema.sql', 'idle_shutdown/db')]`

## VERSIONINFO (build/version.txt)
Standard PyInstaller version-resource template populated with:
- `CompanyName`: `IdleShutdownRestore`
- `ProductName`: `Idle Shutdown & Session Restore`
- `FileDescription`: `Idle Shutdown & Session Restore`
- `FileVersion` / `ProductVersion`: matches `pyproject` `version`.
- `OriginalFilename`: `idle-shutdown.exe`

## Output
`dist/idle-shutdown.exe`. This is the ONLY shipping artifact. No installer in MVP — user copies the exe to any folder and runs `idle-shutdown.exe install-autostart` once.

## Code signing
Out of scope for MVP. Document SmartScreen warning in README.

## Reproducible build
- `pip install --no-deps -r requirements.lock` before `pyinstaller`.
- `requirements.lock` is generated by `pip-compile` from `pyproject.toml`.
- Build script `build/build.ps1` performs: clean → install → pyinstaller → SHA256 of artifact printed to stdout.
